# 星速卡丁车 · STAR KART

一个仿马里奥赛车风格的 3D 卡丁车网页游戏（Three.js）。

## 怎么玩

双击 `star-kart.html` 用浏览器打开即可（需要联网加载 3D 引擎和字体）。

## 操作说明

### 单人

| 按键 | 作用 |
| --- | --- |
| `↑` / `W` | 油门 |
| `↓` / `S` | 刹车 / 倒车 |
| `←` `→` | 转向 |
| `空格` / `Shift` | 跳跃漂移：按住转弯蓄力，松开加速 |
| `E` / `X` | 使用道具（香蕉和弹壳可按住挂在车尾挡攻击，松开发射；同时按 `↓` 往后丢） |
| `C` | 后视 |
| `Esc` | 暂停 |
| `M` | 静音 |

### 双人

| | 驾驶 | 漂移 | 道具 |
| --- | --- | --- | --- |
| 1P | `W` `A` `S` `D` | `空格` | `E` |
| 2P | `↑` `←` `↓` `→` | `右 Shift` / `/` | `Enter` / `.` |

### 触屏

屏幕下方有 ◀ ▶、漂移、刹车、道具按钮。

### 小技巧

- 倒数到“1”时按住油门可以火箭起步
- 跳台上腾空时按漂移键可以做特技，落地加速
- 紧跟在别人车后面能吸尾流加速
- 金币最多 10 枚，越多极速越高
