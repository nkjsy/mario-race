# 星速卡丁车 · STAR KART

一个仿马里奥赛车风格的 3D 卡丁车网页游戏（Three.js）。

## 怎么玩

在线玩：https://nkjsy.github.io/mario-race/

本地玩：双击 `star-kart.html` 用浏览器打开即可（需要联网加载 3D 引擎和字体）。

## 操作说明

游戏菜单右上角和暂停菜单里都有「操作说明」按钮，可以随时查看。

### 单人

| 按键 | 作用 |
| --- | --- |
| `↑` / `W` | 油门（菜单里「自动加速」默认打开，不按也会往前开；关掉后要按住） |
| `↓` / `S` | 刹车 / 倒车 |
| `←` `→` / `A` `D` | 转向 |
| `空格` / `Shift` | 跳跃漂移：按住转弯蓄力，松开加速 |
| `E` / `X` | 使用道具（香蕉和弹壳可按住挂在车尾挡攻击，松开发射；同时按 `↓` 往后丢） |
| `C` | 后视 |
| `Esc` / `P` | 暂停 |
| `M` | 静音 |

### 手柄（按马里奥赛车 8 的布局）

| 按键 | 作用 |
| --- | --- |
| A（右边的键） | 油门 |
| B（下边的键） | 刹车 / 倒车 |
| 左摇杆 / 十字键 | 转向（拿着香蕉或弹壳时往后推再松开道具键，就往后丢） |
| R / ZR | 跳跃漂移 |
| L / ZL | 使用道具 |
| X（上边的键） | 看后方 |
| + / Start | 暂停；在菜单里按它开始比赛 |

双人对战时第一个手柄给 1P，第二个给 2P。

### 双人（上下分屏，两人各用键盘一边）

| | 油门 / 刹车 | 转向 | 漂移 | 道具 | 后视 |
| --- | --- | --- | --- | --- | --- |
| 1P（键盘左边） | `W` / `S` | `A` `D` | `左 Shift` / `F` | `E` / `Q` | `R` |
| 2P（键盘右边） | `↑` / `↓` | `←` `→` | `右 Shift` / `小键盘 0` | `Enter` / `小键盘 .` | `右 Ctrl` / `小键盘 1` |

也可以接两个手柄，第一个给 1P，第二个给 2P。比赛开始时每人的半屏下方会显示自己的按键。

## 公平规则

电脑和玩家用完全相同的规则：没有追赶加速（橡皮筋），火箭起步和道具转盘的规则一样，拿到什么道具只看当前名次。发车位置随机，大奖赛第 2 场起按积分排，积分最高的排最后。难度（50cc–200cc）只影响电脑开车的水平。电脑也会按道具键提前停下转盘、也会把弹壳等道具往后丢；改装时电脑只从你已经解锁的零件里随机挑。「智能转向」「自动道具」是玩家可选的辅助，默认关闭。

### 触屏

油门自动踩住。屏幕下方有 ◀ ▶、漂移、刹车、道具按钮。双人对战需要键盘。

### 小技巧

- 倒数的“2”出现后马上按住油门可以火箭起步，按太早会起步失败
- 跳台上腾空时按漂移键可以做特技，落地加速
- 紧跟在别人车后面能吸尾流加速
- 道具箱撞碎后很快会重新出现；道具转盘转动时按道具键能让它马上停下
- 金币最多 10 枚，越多极速越高
- 有些弯道外侧没有护栏，冲出去会掉下去，云朵会把你送回赛道
- 蓝色跳台是滑翔跳台，飞起来自动展开滑翔翼
- 海底遗迹在水下，重力变小，跳得更高更远；沙漠神殿有沙尘暴
- 彩虹之路在太空里，弯道外侧大多没有护栏，小心别飞出去
- 反重力路段（两边亮蓝色灯带）车轮会翻成悬浮状态，撞车双方都会转圈加速
- 菜单里可以开「智能转向」（快冲出赛道时自动拉回）和「自动道具」（自动找时机用道具），适合新手
- 改装：比赛里吃到的金币加名次奖励会累计，攒够就能解锁新车身、轮胎和滑翔翼；零件有得有失，电脑也从同一批零件里随机挑；进度自动存档
- 比赛结束后点「🎬 最快圈回放」用电影镜头回看最快的一圈

## 道具

可以同时存两个道具：道具框右上角的小圈是第二个，第一个用完自动补上。

| 道具 | 效果 |
| --- | --- |
| 🍌 香蕉皮 | 丢在路上让人打滑，可挂在车尾挡攻击 |
| 🟢 绿色弹壳 / 🔴 追踪红弹 | 直线发射会反弹 / 自动追前一名 |
| 🚀 加速火箭 / 三连火箭 | 瞬间加速 |
| ⭐ 无敌星 | 无敌又加速，撞飞别人 |
| 🪙 金币 | 直接加 2 枚金币 |
| 🦑 墨鱼喷墨 | 糊住前面车手的屏幕 |
| ⚡ 缩小闪电 | 除你以外全体变小减速 |
| 🎯 追冠导弹 | 从天而降打第一名 |
| 📯 超级喇叭 | 震飞身边的车和道具，能炸掉追冠导弹 |
| 🚅 子弹冲锋 | 变成炮弹自动驾驶猛冲，撞飞路上的车，越靠后冲得越久 |
| 🪃 回旋镖 | 扔出去会飞回来，来回都能打人，可扔 3 次 |
| 🔥 火焰花 | 几秒内连按发射弹跳火球 |
| 🌱 食人花 | 车头的花自动咬前面的车和道具，咬到会加速；按道具键向前冲 |
| 🎱 幸运 8 | 一次拿到 8 个道具，按一下用一个 |
| 💣 炸弹 | 扔出去落地后有人靠近就爆炸，范围很大 |

## 模式

| 模式 | 说明 |
| --- | --- |
| 单场比赛 | 选一条赛道，和 7 名电脑对手跑 3 圈 |
| 大奖赛 | 星星杯（阳光草原、落日海湾、彩虹城市）、月亮杯（雪山小镇、熔岩火山、糖果乐园）或彩虹杯（沙漠神殿、海底遗迹、彩虹之路）连跑 3 场，按名次积分，最后颁奖 |
| 赛季 | 按真实赛历跑 24 站经典赛道，按 F1 规则积分（25-18-15-12-10-8-6-4），有车手积分榜和车队积分榜（烈焰、薄荷、岩石、橙雪四队，每队两人），每站结束自动存档，下次接着跑 |
| 双人对战 | 同一台电脑上下分屏 |
| 对战模式 | 霓虹竞技场里四种玩法：气球大战、抢金币（2 分钟金币最多的赢）、抢夺闪光（累计拿着闪光 20 秒就赢）、炸弹大战（道具只有炸弹） |
| 自定义规则 | 单场比赛和双人对战可改道具（正常 / 疯狂 / 只有弹壳 / 只有香蕉 / 只有加速 / 无道具）、电脑水平、圈数、红蓝组队 |
| 计时赛 | 一个人跑，记录最快圈并生成幽灵车；每条赛道保存前 5 名总时间排行榜 |

## 赛道

- **卡丁车赛道**（9 条）：三个杯赛，每条形状、绕圈方向和长度都不一样，有跳台、滑翔、反重力和悬崖。
- **经典赛道**（40 条）：真实赛车场的布局，包括摩纳哥、银石、蒙扎、斯帕、铃鹿、英特拉格斯等。为了让卡丁车能跑，太急的弯放宽了一点，挨得太近的路段稍微拉开；铃鹿的 8 字交叉做成了立交桥。小地图上北方朝上。

经典赛道的布局数据来自开源项目 [bacinger/f1-circuits](https://github.com/bacinger/f1-circuits)（MIT 许可）。本游戏是非官方作品，与 F1 及相关公司无关。
