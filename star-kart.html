操作说明

键盘（单人）

↑ 或 W油门。菜单里「自动加速」默认打开，不按也会一直往前开（和马里奥赛车的自动加速辅助一样）；关掉后就要按住
↓ 或 S刹车，停下后继续按是倒车
←→ 或 AD转向
空格 或 Shift跳跃漂移：转弯时按住，车尾冒出蓝→橙→紫火花后松开，就能加速
E 或 X使用道具。香蕉和弹壳可以按住挂在车尾挡攻击，松开发射；同时按住 ↓ 就往后丢
C按住看后方
Esc 或 P暂停
M静音

双人对战（同一台电脑，上下分屏，两人各用键盘一边）

1P（上半屏）
键盘左边		W 油门，S 刹车，AD 转向，左 Shift 或 F 漂移，E 或 Q 道具，R 后视
2P（下半屏）
键盘右边		↑ 油门，↓ 刹车，←→ 转向，右 Shift 或 小键盘 0 漂移，Enter 或 小键盘 . 道具，右 Ctrl 或 小键盘 1 后视

手柄（按马里奥赛车 8 的布局）

A（右边的键）油门
B（下边的键）刹车，停下后继续按是倒车
左摇杆 / 十字键转向；拿着香蕉或弹壳时往后推再松开道具键，就往后丢
R 或 ZR跳跃漂移
L 或 ZL使用道具（按住挂在车尾）
X（上边的键）看后方
+ / Start暂停；在菜单里按它开始比赛
  • 双人对战时，第一个手柄给 1P，第二个给 2P，键盘也能同时用。Xbox 手柄按位置对应：右边的 B 键是油门，下边的 A 键是刹车。

手机和平板

  • 油门自动踩住。屏幕下方 ◀ ▶ 转向，「漂移」按住蓄力，「刹车」刹车/倒车，「道具」使用道具。
  • 双人对战需要键盘，手机上不能选。

小技巧

  • 火箭起步：倒数的「2」出现后马上按住油门（手柄 A），到 GO 时冲出去。按得太早（「3」还在时就按）会起步失败。开着自动加速也要自己按。
  • 加速带：压过地上的箭头会加速；跳台上腾空时按漂移键做特技，落地加速。
  • 吸尾流：紧跟在别人车后一会儿，会有风线并自动加速。
  • 道具箱：撞碎后很快会重新出现；道具转盘转动时按道具键能让它马上停下，再按一次才是使用。
  • 金币：最多 10 枚，越多极速越高，被打中会掉 3 枚。
  • 辅助选项（菜单里）：「智能转向」会在快冲出赛道时帮你拉回来；「自动道具」会替你找时机用道具。适合新手和小朋友。
  • 改装：比赛里吃到的金币加上名次奖励会累计起来，攒够就能在菜单「改装」里解锁新车身、轮胎和滑翔翼。每种零件都有得有失，电脑车手也从同一批零件里随机挑。进度和选择会自动存档。
  • 比赛结束后点「🎬 最快圈回放」，可以用电影镜头回看你最快的一圈。
  • 开出路面到草地或沙地会变慢；有些弯道外侧没有护栏，冲出去会掉下去，云朵会把你送回赛道（耽误两秒多）。开反方向屏幕上会提示「逆行！」。
  • 蓝色跳台是滑翔跳台：飞起来会自动展开滑翔翼，在空中能飞很远，还能转向。
  • 反重力路段（两边亮蓝色灯带）：车轮会翻成悬浮状态，这时和别的车相撞双方都会转圈加速。

道具

🍌 香蕉皮：丢在路上让人打滑
🟢 绿色弹壳：直线发射，会反弹
🔴 追踪红弹：自动追前面的车
🚀 加速火箭 / 三连火箭：瞬间加速
⭐ 无敌星：无敌又加速，撞飞别人
🪙 金币：直接加 2 枚金币
🦑 墨鱼喷墨：糊住前面车手的屏幕
⚡ 缩小闪电：除你以外全体变小减速
🎯 追冠导弹：从天而降打第一名
📯 超级喇叭：震飞身边的车和道具，能炸掉追冠导弹
🚅 子弹冲锋：变成炮弹自动驾驶猛冲，撞飞路上的车（越靠后冲得越久）
🪃 回旋镖：扔出去会飞回来，来回都能打人，可扔 3 次
🔥 火焰花：几秒内连按发射弹跳火球
🌱 食人花：车头的花自动咬前面的车和道具，咬到会加速；按道具键向前冲
🎱 幸运 8：一次拿到 8 个道具，按一下用一个
💣 炸弹：扔出去落地后有人靠近就爆炸，范围很大

道具箱可以存两个道具：右上小圈是第二个，第一个用完自动补上。

模式

单场比赛选一条赛道，和 7 名电脑对手跑 3 圈
大奖赛星星杯（阳光草原、落日海湾、彩虹城市）、月亮杯（雪山小镇、熔岩火山、糖果乐园）或彩虹杯（沙漠神殿、海底遗迹、彩虹之路）连跑 3 场，按名次积分，最后颁奖。选哪条赛道就跑哪个杯
双人对战两人上下分屏，和 6 名电脑对手一起跑
对战模式霓虹竞技场里混战，四种玩法：气球大战（被打中少一个气球，掉光出局）、抢金币（2 分钟金币最多的赢，被打中会掉金币）、抢夺闪光（累计拿着闪光 20 秒就赢，被打中或被撞会掉）、炸弹大战（道具只有炸弹）
自定义规则单场比赛和双人对战可以改：道具（正常 / 疯狂 / 只有弹壳 / 只有香蕉 / 只有加速 / 无道具）、电脑水平、圈数、红蓝组队。组队时队友的道具打不到自己人，按名次积分算哪队赢
计时赛一个人跑，开局给 3 个加速火箭。会记录最快圈并生成幽灵车陪你跑；每条赛道保存前 5 名总时间排行榜
公平规则电脑和玩家完全同一套规则：没有偷偷追赶加速，起步、道具转盘时间都一样；拿到什么道具只看当前名次，谁落后都一样；发车位置随机，大奖赛第 2 场起积分最高的排最后。难度只影响电脑开得好不好
